# UI-автотесты для SauceDemo

Набор автоматизированных тестов для интернет-магазина [SauceDemo](https://www.saucedemo.com) с использованием **Playwright** и **Pytest**.  
Проект демонстрирует применение паттернов **Page Object Model** и **Step Objects**, централизованное управление браузером через фикстуры, а также чистую структуру кода.
